# App Store Creative Assets

Make the app's purpose recognizable in its header or search placement. Keep reusable production methods here and each app's claims, brand assets, copy and selected concepts in its project.

## Match the request

- **Discuss or review:** inspect the relevant artwork and evidence, explain the consequential choices, and propose alternatives. Do not turn a discussion into unrequested production.
- **Produce:** use the accepted direction when one exists. For exploration, give concepts stable IDs and distinguish a new direction from an iteration of a favorite. Establish one representative composition before multiplying locales and formats; this is a working method, not an additional permission gate.
- **Revise:** preserve accepted choices outside the requested change. Refresh affected exports, previews, review links, manifests and packages together. Leave unrelated approved artwork intact.

Select the placement and read only its reference:

| Placement | Read | Creative job |
| --- | --- | --- |
| Product-page header | [Headers](references/headers.md) | Express a relevant brand idea that survives the displayed crop. |
| Search-results creative | [Search results](references/search-results.md) | Make the purpose and one useful benefit clear at small size. |

For a screenshot gallery, use `app-store-screenshots` when installed. For a mixed request, keep each deliverable's placement and constraints explicit. These skills work independently; neither is a required dependency of the other. This skill's helper supports still images, not motion validation.

## Ground the artwork

Read repository instructions and the app profile or equivalent brief. Inspect the current icon, exact app-name spelling and capitalization, licensed fonts, colors, supported product behavior, retained captures and selected artwork. Reuse verified evidence already in the task. Refresh a drift-prone fact only when the work relies on it; an unverified price or availability claim does not belong in the creative.

Record placement, audience, one intended takeaway, supported claim and limits, copy per locale, source references, and the selected direction in the existing story or manifest. Keep this as the source for dependent copy and labels. Preserve the difference between current app code, a retained capture and the public listing.

Before production, check Apple's current [creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications) and relevant [asset guidance](https://developer.apple.com/app-store/asset-best-practices/). Record the chosen placement/format, URL and check date. A previously used canvas or locally estimated crop is not a permanent platform rule. If verification is unavailable, continue independent design preparation and identify the unresolved export constraint.

## Build from the right sources

Choose photography, illustration, graphic design or actual product UI according to the brief. A header can express the product without depicting its interface. Generated imagery may supply an illustration or scene; it must not fabricate the app's UI or a real customer's experience. Use the available image-generation/editing workflow where appropriate and record prompts, references, selected output, edits and any resizing. Save generated originals in durable project storage before referencing temporary tool outputs.

When showing UI, inspect the original capture first. Use the intended app appearance from a running app on a simulator or device; snapshot-test goldens and windowless reference renders do not establish runtime materials or system chrome. Reuse an existing runtime capture when its provenance and visible appearance fit the intended release; a request for a fresh capture needs a new one. Record source path/hash, dimensions, build/date, appearance, language and whether example data is fictional. If capture is blocked, finish independent layout preparation and clearly identify the missing product evidence.

Preserve software pixels. Uniformly scale the source within the chosen frame or deliberate crop; do not redraw text, controls, status bars or success states. A frame may add a hardware cutout absent from the capture, provided it neither duplicates one nor masks app content. Make changes to the surrounding composition rather than retouching the interface. Use each authentic appearance separately instead of simulating dark mode from a light image.

Keep editorial text editable where practical. Match each app's own identity; a successful design for one app is not a default palette, typeface or metaphor for another. Respect the requested editor and reuse a suitable renderer. The helper below validates finished images; it does not prescribe a rendering stack.

## Fit, inspect and deliver

Preserve approved headline wording and case. Measure the longest localized copy, inspect glyphs and line breaks, and resolve fit through the authorized layout choices. Treat requested approximate type sizes as a starting point; explain a material adjustment. If exact copy and fixed geometry cannot both fit, make the tradeoff concrete before asking. Localizing marketing copy does not translate the app capture: obtain real localized UI when required, or clearly state the retained UI language.

For export requirements, review expectations and the optional helper, read [Export and review](references/export-and-review.md). Check every distinct composition at full size, at a useful thumbnail size, and in relevant crop/overlay views. Measure bounds and verify image properties, then inspect visually; automation cannot judge recognition, natural geometry or readability by itself.

Deliver editable source/provenance, requested final images, an accessible review location, relevant checks, and material limitations. Keep produced, user-selected, uploaded, submitted, Apple-approved, assigned and published states distinct. Creating artwork grants no additional release action; reuse explicit authorization already given and follow the project's release workflow. Never infer a conversion improvement from visual polish.
