# Product-page headers

Read when creating or assessing a product-page header. For a search creative, use the separate search reference rather than assuming the wide header can simply be cropped.

## Find a product-relevant idea

State what the scene should communicate about the app before describing its style. A daily-planning app might evoke preparing to leave; a relationship app might evoke remembering a shared moment. These are illustrative reasoning examples, not mandatory motifs. Literal UI, realistic photography, crafted illustration and abstraction can all fit when the connection to the product is clear. Do not force realism as a platform requirement.

For requested options, vary the underlying idea, focal subject or composition—not just color grading. Explain each option in one sentence about the product. Retain stable concept IDs across rounds so a later selection cannot be confused with an earlier favorite. Record keep, iterate, drop and selected decisions in the existing project story. Do not restart exploration after the user has chosen a direction.

In an iteration, turn feedback into observable changes: seating that actually fits two people, appropriately sized objects, a clearer product cue, or a focal subject that survives the crop. Preserve what was selected. When a scene is meant to be realistic, inspect perspective, scale, occlusion and usable space; intentional stylization follows the brief.

## Compose for the displayed window

Check the current Apple template and the actual placement being prepared. Record template-derived bounds separately from estimated device windows, control overlays and local safety margins. Use Apple's App Store Connect preview when available within the authorized workflow; a local crop mockup is an estimate.

Make the primary subject, gesture or product cue readable in the important crop, with secondary scenery allowed to fall away. Check text, faces and key objects against the whole canvas and the displayed window. Where controls/status glyphs overlay the image, inspect their contrast as well as artwork contrast. Prefer changes to focal placement or local contrast over arbitrary blanket darkening.

Use short editorial text only when it improves the idea; a textless header is valid. Produce headed/textless alternatives when requested or useful for a specific comparison, not as an obligatory variant matrix. Localization may require a different line break or type size while preserving the same subject.

## Finish the selected direction

Retain the selected master and its provenance. Render the required dimensions using an appropriate source resolution; if enlargement is needed, record the method and inspect the final detail. A larger pixel count alone is not evidence of better detail. Keep typography separate from generated imagery when exact text matters. Do not regenerate a selected image merely to export it.

Review the full composition and each distinct localized crop. Compare before/after only where the revision needs it. The selected image, active review card, export manifest and archive must agree; older candidates can remain clearly labeled as history.
